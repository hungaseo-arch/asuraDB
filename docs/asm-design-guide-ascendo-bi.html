BS 01 SUMMARY

요약

ASM은 현재 Bootstrap 5.3 기본 테마 사용 중. 이를 아센도 BI 매뉴얼의 브랜드 블루 #0062C6 + 다크 그레이 #333333 + 화이트 체계로 교체하여, 명함·봉투·레터헤드·현판 등 오프라인 매체와 사내 시스템이 하나의 브랜드로 인식되도록 함

현재 ASM

  • Bootstrap 기본 파랑 #0D6EFD — 브랜드 블루와 유사하나 다른 색
  • 본문 폰트 : 브라우저 기본 system-ui
  • 본문 크기 16 px, 표 셀 15.36 px (혼재)
  • 로고 미표시, 활성 메뉴는 굵기로만 구분
  • 모서리 6 px, 그림자 규칙 미정의

목표 (아센도 BI 기준)

  • 브랜드 블루 #0062C6 단일 기준 + 블루 틴트(10 %) 보조
  • 글자 다크 그레이 #333333, 바탕 화이트·연회색
  • 지정서체 Noto Sans KR(웹) — BI 지정 Noto Sans 계열 그대로
  • 헤더 좌측 시그니처 로고 배치 + 상단 4 px 블루 액센트 바(레터헤드 응용)
  • 모서리 6 px 유지(ASM 현재값과 동일) — 절제된 사각 위주의 BI 인상 유지
  • 심볼 그래픽 모티브를 로그인·빈 화면·인쇄물에 워터마크로 사용
중요 — BI 매뉴얼은 인쇄물 기준, 본 가이드는 웹 변환본 BI 매뉴얼(2024-05-23)은 색상 4종·지정서체·로고 규정·응용물 25종만 정의하고, 화면 UI에 필요한 회색 단계·상태색·크기 체계·컴포넌트 규격은 없음. 본 문서는 BI의 주요색·서체·로고 규정은 그대로 준수하고, 나머지는 BI 톤에서 파생 정의함(파생 항목은 각 표에 "파생" 표기). 12장의 코드를 main.css 최하단(Bootstrap import 이후)에 붙여 넣으면 대부분의 화면이 자동 반영
참고 — 기존 가이드(삼탄 TMS 기준 · AsuraDB 기준)와의 관계 기준 시스템만 다르고 문서 구조·ASM 실측값은 동일. 세 가이드 중 하나만 채택하여 적용할 것. 아센도 BI 기준안은 회사 공식 브랜드 규정과 일치한다는 점이 다른 두 안과의 가장 큰 차이

BS 03 COLOR TOKENS

색상 토큰

BI 매뉴얼 BS 05 「전용색상」의 Main Color(Blue · Dark Gray)와 Sub Color(White · Black)를 기준으로, 웹 UI에 필요한 틴트·회색 단계·상태색을 파생. 화면에서 색을 직접 쓰지 말고 반드시 변수명으로 참조

BS 04 LOGO · SYMBOL · MOTIF

로고 · 심볼 · 그래픽 모티브 사용 규정

BI 매뉴얼 BS 01~04, 06~08을 화면 규격으로 변환. 로고 원본 벡터 파일(AI/SVG, 고해상도)은 BI 담당 부서에서 받아 사용하며 재작도 금지 — 본 문서에는 담당 부서 제공 참조용 래스터 이미지를 임시 삽입

4-4. 그래픽 모티브 — 심볼 워터마크 (BS 08)

  • BI 원문 : "심볼을 활용하여 각 모서리 또는 매체의 어디든 위치시켜 사용할 수 있다" — 화면에서는 우하단 모서리 잘림 배치를 표준으로 함(팩스용지 AS 08 · 서류철 AS 11 사례)
  • 색상 : 흰 바탕 위 브랜드 블루 6 % 투명도(#F0F6FC 상당) / 블루 바탕 위 White 10 %
  • 사용 화면 : 로그인, 대시보드 빈 상태(empty state), 404·오류 페이지, 인쇄 미리보기 하단. 데이터 표·입력 폼 뒤에는 사용 금지(가독성 저하)
  • 크기 : 화면 짧은 변의 40 % 내외, 카드 안에서는 카드 높이의 120 %로 잘리게 배치(본 문서 표지 카드 우하단이 예시)

BI와의 의도적 차이 2가지 ① BI 본문용은 Light(300)이나 14 px 화면 본문에서는 가독성이 떨어져 Regular(400)을 기본으로 하고, Light는 18 px 이상 큰 부제·KPI 라벨에만 사용. ② BI 장평 95 %는 인쇄 조판 값이므로 화면에서는 적용하지 않음(font-stretch 미지원 폰트). 인쇄용 PDF 출력물(견적서·PO)에서는 BI 원칙대로 KoPub 돋움 + 장평 95 % 적용 권장

BS 06 RADIUS · SPACING · SHADOW

6-1. 모서리 (radius)

BI 응용물(명함·봉투·명패·서류철)은 모두 직각 또는 최소 라운드. 화면에서는 클릭 요소 인지를 위해 소폭 라운드만 허용 — 기준값 0.375rem(6 px), ASM 현재값과 동일하므로 추가 작업 없음

토큰값적용

6-2. 간격 (spacing)

4 px 배수만 사용. 4 / 8 / 12 / 16 / 20 / 24 / 32. BI 인쇄물의 넉넉한 여백 감각을 살려 카드 내부 패딩 20 × 24 px, 페이지 여백 24 px

4 px아이콘과 글자 사이, 배지 내부 간격, 액센트 바 높이
8 px버튼 간 간격, 배지 좌우 패딩, 라벨-입력창 간격(6 px)
12 px입력창 좌우 패딩, 표 셀 좌우 패딩, 헤더 요소 간격
16 px폼 항목 간 세로 간격, 카드 간 간격, 본문 여백(모바일)
