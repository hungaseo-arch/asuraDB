espanso 클라우드 동기화 구축 가이드

텍스트 대치(text expander) 설정을 클라우드 한 곳에 두고, Windows PC와 Mac이 동일한 대치 규칙을 공유하도록 구성하는 절차서. 실제 구축 과정에서 확인된 실패 원인과 해결책을 포함한다.

1개요

espanso(에스판소)는 오픈소스 텍스트 대치 프로그램이다. :asc 같은 짧은 키워드를 입력하면 미리 정한 문장으로 자동 치환된다. 설정이 YAML 텍스트 파일이므로, 설정 폴더 원본을 클라우드에 두고 각 OS의 기본 경로를 심볼릭 링크(symlink)로 대체하면 Windows와 Mac이 하나의 규칙을 공유한다.

2최종 구조

2.1 클라우드 원본 — 단일 진실 소스

G:\내 드라이브\04-ETC\espanso\ ← Windows에서 본 경로 ~/Library/CloudStorage/GoogleDrive-<계정>/내 드라이브/04-ETC/espanso/ ← Mac에서 본 경로 ├── config/ │ └── default.yml 프로그램 동작 설정 └── match/ ├── base.yml 실제 대치 규칙 (주 편집 대상) └── packages/ 허브에서 설치한 패키지
⚠ 필수 조건

config와 match 두 하위 폴더가 반드시 존재해야 한다. base.yml 파일 하나만 두면 missing config directory 오류가 발생한다.

2.2 각 OS의 링크 위치

OSespanso 기본 설정 경로처리
WindowsC:\Users\<계정>\AppData\Roaming\espanso폴더 → 심볼릭 링크로 대체
macOS~/Library/Application Support/espanso폴더 → 심볼릭 링크로 대체

경로 확인 명령: espanso path

3공통 원칙 3가지

이 세 가지를 지키지 않으면 반드시 실패한다. 실제 시행착오에서 확인된 항목이다.

원칙 1espanso 프로세스를 완전히 죽인 뒤 작업한다

가장 중요하다. espanso는 백그라운드 서비스로 동작하며, 설정 폴더가 사라지면 즉시 기본 폴더를 재생성한다. 삭제 직후 폴더가 되살아나 링크 생성이 실패하거나, 링크가 엉뚱한 위치에 만들어진다.

  • 서비스 등록 해제까지 해야 완전히 멈춘다 — espanso service unregister
  • 프로세스 강제 종료를 병행한다 — pkill -9 -i espanso / taskkill /F /IM espanso.exe /T

원칙 2삭제와 링크 생성을 한 줄로 연결한다

두 명령 사이의 시간차에 폴더가 재생성될 수 있으므로 ; 또는 &&로 연결해 한 번에 실행한다.

원칙 3링크 이름 자리에 폴더가 남아 있으면 안 된다

ln -s 대상 링크이름 에서 링크이름이 이미 존재하는 폴더면, 링크가 그 폴더 "안에" 생성된다. 결과적으로 espanso/espanso -> ... 같은 중첩 구조가 되어 오류가 난다.

검증 방법 — 목록의 첫 글자

정상 lrwxr-xr-x  … espanso -> /Users/…/04-ETC/espanso
실패 drwxr-xr-x  … espanso

l이면 심볼릭 링크, d면 실제 폴더다. d가 나오면 원칙 1·2로 돌아간다.

4Windows 설정 절차

1설치
cmd
winget install Espanso.Espanso

또는 espanso.org에서 설치 파일을 내려받아 설치한다.

2클라우드에 원본 폴더 준비 (최초 1회)
  1. espanso stop 실행
  2. 탐색기 주소창에 %APPDATA% 입력 → espanso 폴더를 잘라내기
  3. G:\내 드라이브\04-ETC\ 에 붙여넣기
  4. config와 match 하위 폴더가 있는지 확인
3링크 생성 — 관리자 권한 명령 프롬프트
cmd · 관리자
espanso service unregister
taskkill /F /IM espanso.exe /T

rmdir "%APPDATA%\espanso"
mklink /D "%APPDATA%\espanso" "G:\내 드라이브\04-ETC\espanso"

espanso service register
espanso start
4검증
cmd
dir /a "%APPDATA%"
espanso status
espanso path

espanso 항목이 <SYMLINKD>로 표시되면 정상이다.

⚠ Windows 주의사항
  • mklink는 반드시 관리자 권한이 필요하다.
  • 경로에 <계정> 같은 자리표시자를 그대로 넣으면 <, >가 금지 문자라 구문 오류가 난다. 위처럼 %APPDATA%를 쓰면 계정명을 적을 일이 없다(계정명 확인은 echo %USERNAME%).
  • /D는 폴더 링크, 옵션 없음은 파일 링크다. 대상 유형과 맞춰야 한다.
  • rmdir은 심볼릭 링크일 경우 링크만 제거하므로 원본은 안전하다.

5macOS 설정 절차

1설치
zsh
brew install espanso

CLI가 인식되지 않으면 (command not found: espanso):

zsh
sudo ln -s /Applications/Espanso.app/Contents/MacOS/espanso /usr/local/bin/espanso
2권한 부여 (필수)

시스템 설정 → 개인정보 보호 및 보안에서 아래를 모두 설정한다.

권한 항목대상목적
손쉬운 사용 (Accessibility)Espanso텍스트 대치 동작
입력 모니터링 (Input Monitoring)Espanso키 입력 감지
전체 디스크 접근 권한 (Full Disk Access)Espanso, 터미널~/Library/CloudStorage 접근
⚠ 적용 방법

전체 디스크 접근 권한 없이는 터미널에서 Google Drive 경로 조회 시 Operation not permitted 오류가 발생한다. 권한 부여 후 터미널을 ⌘Q로 완전히 종료한 뒤 재실행해야 적용된다.

3Drive 경로 확인
폴더명이 로케일에 따라 다르다

한국어 계정은 My Drive가 아니라 내 드라이브이다. 이 차이가 링크 실패의 흔한 원인이므로 반드시 실제 값을 확인한다.

zsh
ls -la ~/Library/CloudStorage/
ls -la ~/Library/CloudStorage/GoogleDrive-<계정>@gmail.com/
4링크 생성
zsh
DRIVE="$HOME/Library/CloudStorage/GoogleDrive-<계정>@gmail.com/내 드라이브/04-ETC"
LOCAL="$HOME/Library/Application Support/espanso"

# 프로세스 완전 종료
espanso service unregister
pkill -9 -i espanso
sleep 2
pgrep -il espanso          # 출력이 없어야 함

# 삭제와 링크 생성을 한 줄로
rm -f "$LOCAL/espanso"; rm -rf "$LOCAL" && ln -s "$DRIVE/espanso" "$LOCAL"

# 검증 — 반드시 'l'로 시작해야 함
ls -la "$HOME/Library/Application Support/" | grep espanso
ls "$LOCAL/"               # config  match 두 개가 나와야 함

# 기동
espanso service register
espanso start
espanso status
espanso path

8부록 · 기본 사용법

8.1 대치 규칙 작성 — match/base.yml

yaml
matches:
  # 단순 치환
  - trigger: ":asc"
    replace: "PT Ascendo Internasional"

  # 여러 줄 (이메일 서명)
  - trigger: ":sig"
    replace: |
      Best regards,
      Seo / General Manager
      PT Ascendo Internasional

  # 오늘 날짜 자동 입력
  - trigger: ":date"
    replace: "{{today}}"
    vars:
      - name: today
        type: date
        params:
          format: "%Y-%m-%d"

  # 입력 폼 (빈칸 채우기)
  - trigger: ":quote"
    replace: "Dear {{name}}, please find attached our quotation for {{item}}."
    vars:
      - name: form1
        type: form
        params:
          layout: "Name: [[name]]  Item: [[item]]"
      - name: name
        type: echo
        params: { echo: "{{form1.name}}" }
      - name: item
        type: echo
        params: { echo: "{{form1.item}}" }

8.4 트리거 작명 규칙

  • 반드시 : 또는 ; 등 접두 기호를 붙인다. pt 같은 일반 단어를 트리거로 쓰면 평소 타이핑 중 오작동한다.
  • 한국어·인도네시아어 등 유니코드 치환은 정상 동작한다.
  • OS별로 달라야 하는 항목(type: shell 등)은 match/win.yml, match/mac.yml로 분리하고 공용 항목만 base.yml에 둔다.
