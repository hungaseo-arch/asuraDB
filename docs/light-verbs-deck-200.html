구동사가 동사 + 불변화사라면, 경동사는 비어 있는 동사 + 동작 명사입니다. 의미의 무게는 동사가 아니라 명사에 실립니다. 그래서 어느 동사를 붙이는가가 곧 실력입니다. decide → make a decision, order → place an order, claim → file a claim.

한국어·인도네시아어 화자가 무역 서신에서 반복하는 오류입니다. 대부분 명사는 맞는데 동사를 잘못 고른 경우이며, 상대방은 뜻은 알아듣되 비원어민 문장으로 인식합니다. 계약서·클레임 레터처럼 문언이 남는 문서에서는 특히 교정 가치가 큽니다.

영상은 카드 → 영상 → 목록 순서로 쓰십시오. 먼저 카드에서 이미지를 잡고, 영상으로 원어민 발화 속 쓰임을 듣고, 마지막에 목록에서 문서 유형별로 복습하는 순환입니다. 각 영상 아래의 버튼이 해당 카드와 표현 묶음으로 바로 연결됩니다.

카드 덱은 경동사 12개의 핵심 이미지를 심기 위한 것이고, 전체 목록은 그 이미지 아래에 연어를 매다는 용도입니다. 순서는 덱 → 목록 → 오류 교정 → 영상 학습입니다.
영상은 클릭하면 그 자리에서 재생됩니다. 재생 전에는 외부 요청이 발생하지 않으며, 시청 완료 표시는 새로고침하면 초기화됩니다.
원칙: 대외 공식 문서(견적서·발주서·인보이스·클레임·계약서)는 경동사 구문, 사내 보고와 단문 메일은 단일 동사를 씁니다.
